Instalación, configuración y soporte de software

Instalación, configuración y soporte de sistema operativo y programas, con ayuda para que empieces a usarlos con confianza.

Solicitar presupuesto

Problemas que puede ayudar a resolver

  • Un programa que no se instala o falla
  • Un equipo nuevo por configurar
  • Dudas con el sistema o con un programa concreto

Qué incluye

  • Instalación y configuración de los programas acordados
  • Ajustes iniciales del sistema
  • Explicación básica de uso

Qué no incluye

  • Licencias de software (se indican aparte)
  • Soporte para programas sin licencia válida

Información que necesitamos para valorarlo

  • Sistema operativo y programas que quieres instalar
  • Si tienes licencia o cuenta para cada programa
  • Qué error aparece o qué quieres aprender a hacer

Posibles costes adicionales

Si hace falta algún componente o licencia, se presupuesta aparte de la mano de obra y no se compra nada sin tu aceptación. Consulta las tarifas.

Preguntas frecuentes

¿Las licencias están incluidas?

No. Si un programa necesita licencia, se indica en el presupuesto, separada de la mano de obra.

¿Podéis instalar programas sin licencia?

No damos soporte a programas sin licencia válida. Si existen alternativas gratuitas y legales, te las explicamos.
